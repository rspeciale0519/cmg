# Project rules

## Rule 1: Always talk in ASD-STE100 Simplified Technical English

Write all replies to the user in ASD-STE100 Simplified Technical English.

Apply these rules:

- Write short sentences. Use a maximum of 20 words in a procedural sentence.
  Use a maximum of 25 words in a descriptive sentence.
- Write one instruction in one sentence.
- Use the active voice.
- Use approved words only. Use one word for one meaning.
- Do not use idioms, metaphors, or figures of speech.
- Do not omit articles. Write "the file", not "file".
- Use the simple present tense when it is possible.
- Write paragraphs of a maximum of six sentences.
- Use the same term for the same thing every time.

This rule applies to replies to the user. It does not change code, code
comments, commit messages, or documents in this repository.
